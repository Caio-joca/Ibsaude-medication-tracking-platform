# Escopo funcional entregue

O IBSAÚDE cobre o ciclo completo previsto para o MVP institucional: autenticação, perfis, cadastros, aquisições, documentos, estoque por lote, FEFO, distribuições, devoluções, ajustes, auditoria, rastreabilidade, painel e relatórios.

## Limites conscientes

- O sistema não substitui validação farmacêutica, jurídica, de LGPD ou de infraestrutura feita por profissionais formalmente responsáveis.
- O deploy foi preparado, mas publicar exige uma conta de nuvem e autorização do titular.
- A migração real para PostgreSQL exige uma instância de destino e credenciais; o schema, o driver, a migration e o script de cópia estão prontos.
- O documento formal de saída é aceito em PDF/XML; a definição de obrigatoriedade e do modelo oficial deve ser homologada pela instituição.

Esses itens constam no checklist de validação para não serem confundidos com defeitos de implementação.
